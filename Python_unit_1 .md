### 📝 Exam Definition (English):

### 📝 Exam Definition (English):

```text
Features of Python:

1. Simple and Easy to Learn:
   Python has a clean and readable syntax that

   Python code is executed line by line by the
   interpreter. There is no need for a separate
   compilation step, which makes debugging easier.

   Python can be extended with C/C++ code for

   Python can accomplish complex tasks in fewer
   lines of code compared to other languages.

    Python supports procedural, object-oriented,
```

## Part 5: Limitations of Python (Exam Mein Aa Sakta Hai ⚡)

### 🗣️ Hinglish Explanation:

```text
Python perfect nahi hai. Kuch kamiya bhi hain:

1. SLOW hai → C/C++ ke comparison mein bahut slow
   Kyunki interpreted hai, compiled nahi

2. Mobile Development mein weak → Android/iOS
   apps ke liye best nahi hai

3. Memory zyada leta hai → Har cheez object hai
   toh memory consumption zyada hoti hai

4. Runtime Errors → Type check runtime pe hoti hai
   toh errors baad mein pata chalti hain

5. Database access weak → Java/C# ke comparison
   mein database connectivity kamzor hai

6. Threading limited → GIL (Global Interpreter
   Lock) ki wajah se true parallel processing
   nahi hoti

7. Design restrictions → Dynamic typing ki wajah
   se bade projects mein bugs aa sakte hain
```

### 📝 Exam Definition (English):

```text
Limitations / Disadvantages of Python:

1. Slow Execution Speed:
   Python is an interpreted language, which makes
   it slower compared to compiled languages like
   C, C++, and Java. Each line is interpreted at
   runtime, adding overhead.

2. High Memory Consumption:
   Python uses more memory than other languages
   because everything in Python is an object.
   This makes it unsuitable for memory-intensive
   applications.

3. Not Ideal for Mobile Development:
   Python is rarely used for mobile app development.
   Languages like Java (Android) and Swift (iOS)
   are preferred for mobile platforms.

4. Runtime Errors:
   Since Python is dynamically typed, type-related
   errors are detected only at runtime, not during
   compilation. This can cause unexpected crashes.

5. Limited Database Access:
   Python's database access layers are relatively
   underdeveloped compared to technologies like
   JDBC in Java or ADO.NET in C#.

6. Threading Limitations (GIL):
   Python's Global Interpreter Lock (GIL) prevents
   multiple threads from executing Python bytecodes
   simultaneously, limiting true parallel processing.

7. Not Suitable for Game Development:
   While Pygame exists, Python is not the preferred
   choice for high-performance game development.
   C++ and C# (Unity) are better options.
```

```text
print() = Screen pe kuch dikhana

```

### 📝 Exam Definition (English):

```text
The print() Function:

The print() function is a built-in Python function
used to display output on the console/screen.

Syntax:
print(*objects, sep=' ', end='\n', file=sys.stdout)

Parameters:
1. objects: One or more values to be printed.
2. sep: Separator between values (default: space).
3. end: Character at the end of output
        (default: newline '\n').
4. file: Where to print (default: screen).

  print("Hello World")
  Output: Hello World

  print("A", "B", "C", sep="-")
  Output: A-B-C

  print("Hello", end=" ")
  print("World")
  Output: Hello World

Escape Sequences:
  \n  → New Line
  \t  → Horizontal Tab
  \\  → Backslash
  \'  → Single Quote
  \"  → Double Quote
  \r  → Carriage Return
  \b  → Backspace
  \a  → Alert/Bell

String Formatting Methods:

1. f-string (Python 3.6+):
   name = "Rahul"
   print(f"Name is {name}")
   Output: Name is Rahul

2. format() method:
   print("Name: {}".format("Rahul"))
   Output: Name: Rahul

3. % operator (old style):
   print("Name: %s" % "Rahul")
   Output: Name: Rahul
```

## Part 11: Statements vs Expressions

### 🗣️ Hinglish Explanation:

```text
Expression = Kuch VALUE produce karta hai
  2 + 3 → 5 (value mili)

Statement = Kuch KAAM karta hai
  x = 5 (assignment kaam hai)
  if x > 3: (condition kaam hai)
```

### 📝 Exam Definition (English):

```text
Statements vs Expressions:

Expression:
An expression is a combination of values,
variables, operators, and function calls that
evaluates to produce a single value.
Examples: 2 + 3, len("hello"), x * 5

Statement:
A statement is a complete instruction that
performs some action. It does not necessarily
produce a value.
Examples: x = 5, if x > 3:, print("hi"),
          for i in range(5):

Key Difference:
- Expression → Evaluates to a value
- Statement → Performs an action
```

## Part 13: Variables and Data Types (Full ⚡⚡⚡)

### 🗣️ Hinglish Explanation:

```text
Variable = Data store karne ka dabba
Python mein type batani nahi padti

6 Data Types:
1. int → 10, -5, 0
2. float → 3.14, -2.5
3. complex → 3+4j (real + imaginary)
4. str → "hello", 'python'
5. bool → True, False
6. NoneType → None (kuch nahi)

type() function se type check karte hain
```

### 📝 Exam Definition (English):

```text
Variables:
A variable is a named memory location used to
store data. In Python, variables are dynamically
typed, meaning the data type is determined
automatically at runtime.

Example:
  x = 10      # x is int
  x = "hello" # x is now str

Data Types in Python:

1. Integer (int):
   Represents whole numbers (positive, negative,
   or zero). No size limit in Python.
   Example: x = 10, y = -5, z = 0

2. Float (float):
   Represents decimal numbers.
   Example: x = 3.14, y = -2.5
   Scientific notation: x = 1.5e3 (1500.0)

3. Complex (complex):
   Represents complex numbers with real and
   imaginary parts. Uses 'j' suffix.
   Example: x = 3 + 4j
   x.real → 3.0, x.imag → 4.0

4. String (str):
   Represents a sequence of characters enclosed
   in single, double, or triple quotes.
   Strings are immutable.
   Example: s = "Hello"
   Indexing: s[0] → 'H', s[-1] → 'o'
   Slicing: s[0:3] → "Hel"

5. Boolean (bool):
   Represents truth values: True or False.
   True = 1, False = 0
   Example: x = True, y = (5 > 3) → True

6. NoneType (None):
   Represents the absence of a value.
   Example: x = None

The type() Function:
Used to determine the data type of a variable.
  type(10)    → <class 'int'>
  type(3.14)  → <class 'float'>
  type(3+4j)  → <class 'complex'>
  type("hi")  → <class 'str'>
  type(True)  → <class 'bool'>
  type(None)  → <class 'NoneType'>
```

## Part 14: Type Conversion

### 🗣️ Hinglish Explanation:

```text
Type Conversion = Ek type ko dusri mein badalna

2 Types:
1. Implicit (Auto) → Python khud karta hai
   5 + 3.2 → 8.2 (int auto float ban gaya)

2. Explicit (Manual) → Hum functions use karte hain
   int("10") → 10
   float(5) → 5.0
   str(10) → "10"
   bool(0) → False
```

### 📝 Exam Definition (English):

```text
Type Conversion (Type Casting):

Type conversion is the process of converting
one data type into another.

1. Implicit Type Conversion (Automatic):
   Python automatically converts a smaller data
   type to a larger data type to prevent data loss.
   Hierarchy: bool < int < float < complex
   Example:
     5 + 3.2 → 8.2 (int converted to float)
     True + 5 → 6 (bool converted to int)

2. Explicit Type Conversion (Manual):
   The programmer manually converts data types
   using built-in functions.

   Functions:
   int(x)      → Converts x to integer
   float(x)    → Converts x to float
   str(x)      → Converts x to string
   bool(x)     → Converts x to boolean
   complex(x)  → Converts x to complex
   complex(a,b)→ Creates a+bj

   Examples:
     int(3.14)    → 3
     int("10")    → 10
     float(5)     → 5.0
     str(100)     → "100"
     bool(0)      → False
     bool("")     → False
     bool("hi")   → True
     complex(3,4) → (3+4j)
```

## Part 15: Operators (Full ⚡⚡⚡)

### 🗣️ Hinglish Explanation:

```text
Operators = Values pe kaam karne wale symbols

7 Types:
1. Arithmetic → +, -, *, /, //, %, **
2. Comparison → ==, !=, >, <, >=, <=
3. Logical → and, or, not
4. Assignment → =, +=, -=, *=, /=
5. Bitwise → &, |, ^, ~, <<, >>
6. Identity → is, is not
7. Membership → in, not in
```

### 📝 Exam Definition (English):

```text
Operators in Python:

An operator is a symbol that performs operations
on operands (values or variables).

1. Arithmetic Operators:
   +   Addition         5 + 3 = 8
   -   Subtraction      5 - 3 = 2
   *   Multiplication   5 * 3 = 15
   /   Division         5 / 2 = 2.5 (float)
   //  Floor Division   5 // 2 = 2
   %   Modulus          5 % 2 = 1
   **  Exponentiation   2 ** 3 = 8

2. Comparison (Relational) Operators:
   ==  Equal to         5 == 5 → True
   !=  Not equal        5 != 3 → True
   >   Greater than     5 > 3  → True
   <   Less than        5 < 3  → False
   >=  Greater/equal    5 >= 5 → True
   <=  Less/equal       5 <= 3 → False

3. Logical Operators:
   and → True if both operands are True
   or  → True if at least one operand is True
   not → Reverses the boolean value

4. Assignment Operators:
   =    Assign          x = 5
   +=   Add & Assign    x += 3 (x = x+3)
   -=   Subtract        x -= 3
   *=   Multiply        x *= 3
   /=   Divide          x /= 2
   //=  Floor Divide    x //= 2
   %=   Modulus         x %= 2
   **=  Exponent        x **= 2

5. Bitwise Operators:
   &   AND       5 & 3 = 1
   |   OR        5 | 3 = 7
   ^   XOR       5 ^ 3 = 6
   ~   NOT       ~5 = -6
   <<  Left Shift  5 << 1 = 10
   >>  Right Shift 5 >> 1 = 2

6. Identity Operators:
   is      → True if both refer to same object
   is not  → True if both refer to different objects
   Note: == checks value, is checks memory address

7. Membership Operators:
   in      → True if value exists in sequence
   not in  → True if value does not exist
   Example: "a" in "apple" → True
```

## Part 16: Operator Precedence & Associativity

### 🗣️ Hinglish Explanation:

```text
Precedence = Kaunsa operator pehle chalega
  () sabse pehle
  = sabse last mein

Associativity = Same priority pe direction
  Left to Right (mostly)
  Right to Left (sirf ** aur =)
```

### 📝 Exam Definition (English):

```text
Operator Precedence:

Operator precedence determines the order in
which operators are evaluated in an expression.
Higher precedence operators are evaluated first.

Precedence Table (Highest to Lowest):

Priority  Operator          Description
1         ()                Parentheses
2         **                Exponentiation
3         ~, +x, -x         Unary operators
4         *, /, //, %       Multiplication/Division
5         +, -              Addition/Subtraction
6         <<, >>            Bitwise Shift
7         &                 Bitwise AND
8         ^                 Bitwise XOR
9         |                 Bitwise OR
10        ==,!=,>,<,>=,<=   Comparisons
11        is, is not        Identity
12        in, not in        Membership
13        not               Logical NOT
14        and               Logical AND
15        or                Logical OR
16        =, +=, -=, etc    Assignment

Associativity:
When operators have the same precedence,
associativity determines the direction of
evaluation.

- Left to Right (most operators):
  10 - 5 - 2 = (10-5) - 2 = 3

- Right to Left (exponentiation & assignment):
  2 ** 3 ** 2 = 2 ** (3**2) = 512
  x = y = 5 → x = (y = 5)
```
